# lab11 — Roommate Bill Splitter

## Overview
A single-file C program (`roommate_split.c`) that runs in a Linux terminal.  
It splits a shared bill either equally or by custom percentages.

## How to build and run

```bash
gcc -Wall -Wextra -o roommate_split roommate_split.c
./roommate_split
```

## Stack
- Language: C (C11)
- Compiler: GCC
- No external dependencies

## User preferences
- Keep the project as a single C source file unless the user asks to split it
